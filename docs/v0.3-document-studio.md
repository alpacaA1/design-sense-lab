# Design Sense Lab V0.3 文档工作台

> 状态：已完成（2026-09-15）。

## 目标

将产品从 Document/Web/App 的 A/B/C 判断实验器，收敛为专注文档的单画布工作台。用户围绕一份真实文档调整页面、排版、层级、间距、组件和颜色，并把有效组合保存为自己的样式。

## 当前范围

- 长文档：连续双页、单双栏、页眉页脚。
- 一页纸：单页控制、单双栏内容结构、指标与行动模块。
- 简历：单双栏、侧栏比例、照片和经历结构。
- 正式信件：信头、日期位置、正文和签名留白。
- A4、A5、Letter 三种页面格式。
- Page、Typography、Hierarchy、Spacing、Components、Color 六类参数。
- 单一大画布优先展示文档，移除底部指标栏以减少非必要占位。
- My Styles 保存、筛选和恢复。

## 核心交互

```text
选择文档类型
    ↓
加载独立模板与参数
    ↓
调整参数并实时查看完整画布
    ↓
查看页数、行长和密度反馈
    ↓
保存到 My Styles
    ↓
在后续文档中恢复和修正
```

## 技术结构

| 文件 | 职责 |
|---|---|
| `config.js` | 四种文档类型、六类参数和默认值 |
| `state.js` | 各文档独立状态、参数校验、本地持久化 |
| `controls.js` | 数值、枚举、颜色和开关控件 |
| `renderers.js` | 四种文档模板和指标计算 |
| `styles-library.js` | My Styles 筛选和应用 |
| `app.js` | 工作台协调、Dialog 和导航 |

应用保持纯前端、零第三方依赖。旧版判断记录使用原存储键保留，新版 My Styles 使用独立存储键，不执行破坏性迁移。

## 关键决定

1. 默认只显示一个可阅读的完整文档，不常驻多版本比较。
2. 文档类型不仅替换内容，还拥有独立结构、默认值和专属参数。
3. 移除观察与判断表单，以实时指标和样式保存代替强制反思。
4. Web、App 和产品落地页退出当前范围。
5. 作品集、幻灯片和 Markdown Deck 延后到独立渲染模型。

## 验证

- 状态测试覆盖四种文档、六类参数、范围限制、持久化、样式保存与恢复、指标和重置。
- 浏览器验证覆盖四种模板、实时字号更新、My Styles 完整流程和 390px 响应式布局。
- 视觉规则扫描无告警，浏览器控制台无错误。
